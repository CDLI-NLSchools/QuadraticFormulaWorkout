# Quadratic Formula Workout

A practice app for **Math 2201, Unit 3 — Quadratic Equations** (Section 3: the quadratic formula).

Students solve generated quadratic equations one checked step at a time, in exact form: standard form (for problems that don't start in it), the discriminant, the simplified radical, and the roots. Four problem kinds rotate — direct, standard-form-first, rational roots, and prime discriminant — and equations are built backwards from their exact answers, so every answer key is clean. Each step can be checked as many times as needed, revealed if stuck, and a full worked solution is shown at the end.

Single-file HTML (`index.html`), no external resources — runs offline once loaded.
